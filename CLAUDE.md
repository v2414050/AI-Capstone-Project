# Project Instructions

## Project Overview

This is an AI-assisted capstone project developed to practice
modern software development workflows.

## Technology Stack

- HTML
- CSS
- JavaScript
- Node.js
- Git
- GitHub

## Coding Conventions

- Use clear and descriptive variable names.
- Keep functions small and focused.
- Write clean and readable code.
- Avoid unnecessary code duplication.
- Use comments only when they improve understanding.
- Do not commit API keys, passwords, or other secrets.
- Keep the project structure organized.

## Git Conventions

Use Conventional Commits for all commits.

Examples:

- feat: add a new feature
- fix: fix a bug
- docs: update documentation
- chore: update project configuration
- refactor: improve code structure

## AI Development Guidelines

- Review existing code before making changes.
- Explain significant changes when necessary.
- Do not change the project's technology stack without permission.
- Prefer simple and maintainable solutions.
- Ask before making major architectural changes.
